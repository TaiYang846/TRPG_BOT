# 跑團劇本查詢機器人

輸入 `/劇本 劇本名稱`，機器人就會回覆該劇本的作者、背景、概要、公開HO 等資訊。

---

## 第一步：申請 Discord 機器人帳號

1. 開啟 https://discord.com/developers/applications
2. 點右上角「New Application」，取個名字（例如：跑團小幫手）
3. 左側選單點「Bot」→ 點「Reset Token」→ 複製出現的 Token（**這串文字只會顯示一次，要馬上存起來**）
4. 在同一頁，把「MESSAGE CONTENT INTENT」開關打開（雖然這個機器人用不到，但養成習慣比較保險）

## 第二步：把 Token 填進專案

1. 把 `.env.example` 改名成 `.env`
2. 打開 `.env`，把裡面的文字換成你剛剛複製的 Token，例如：
   ```
   DISCORD_TOKEN=abcdefg1234567.your.real.token
   ```
3. **千萬不要把 `.env` 分享給別人或上傳到公開的 GitHub**，這串 Token 等於你機器人的密碼

## 第三步：安裝環境並執行

需要先安裝 Python 3.9 以上版本（https://www.python.org/downloads/）。

在專案資料夾內開啟終端機（Terminal / 命令提示字元），依序執行：

```bash
pip install -r requirements.txt
python bot.py
```

看到終端機顯示「機器人已上線：xxx」就代表成功了！

## 第四步：把機器人邀請進你的伺服器

1. 回到 Developer Portal，左側選單點「OAuth2」→「URL Generator」
2. 在 SCOPES 勾選 `bot` 和 `applications.commands`
3. 在 BOT PERMISSIONS 勾選 `Send Messages`、`Embed Links` 就夠用了
4. 把畫面最下方產生的網址複製到瀏覽器打開，選擇你的伺服器，點授權

## 第五步：新增/修改你自己的劇本

打開 `scenarios` 資料夾，**每個劇本是一個獨立的 .json 檔案**，檔名（去掉 `.json`）就是劇本名稱，例如 `scenarios/血染鐘樓.json`。

- **新增劇本**：在 `scenarios` 資料夾裡新增一個檔案，檔名取成劇本名稱（例如 `scenarios/迷霧莊園.json`），照格式填入內容
- **修改劇本**：直接打開對應的檔案編輯即可

完全**不需要動到 `bot.py` 的程式碼**，也不會因為改了 A 劇本而不小心弄壞 B 劇本的資料（因為是分開的檔案）。完整欄位說明（含 HO 診斷網址、NPC 清單）請見本文件最下方的「新增劇本資料時的完整欄位」。

> 💡 **在 GitHub 網頁上新增劇本檔案的方法**：進到 repository 裡的 `scenarios` 資料夾 → 點 `Add file` → `Create new file` → 檔名直接打成 `劇本名稱.json`（GitHub 會自動放進 scenarios 資料夾底下，只要檔名前面有打 `scenarios/` 或你本來就在這個資料夾頁面裡新增）→ 貼上內容 → `Commit changes`。

## 目前有的指令

| 指令 | 說明 |
|---|---|
| `/劇本 名稱` | 查詢指定劇本詳細資訊 |
| `/劇本列表` | 列出所有目前收錄的劇本 |
| `/劇本資訊` | **在論壇貼文（討論串）裡面**打這個指令，機器人會自動判斷「這篇貼文對應哪個劇本」，不用輸入名稱 |
| `/ho診斷` | 在論壇貼文裡打這個指令，回覆這個劇本對應的 HO 診斷網址（連結） |
| `/npc介紹` | 在論壇貼文裡打這個指令，列出這個劇本的所有 NPC |
| `/npc 名稱` | 查詢指定 NPC 的介紹，不限定要在哪篇貼文都能查，會列出所有劇本裡符合的 NPC |

### `/劇本資訊`、`/ho診斷`、`/npc介紹` 怎麼對應到正確的劇本？

機器人會拿「目前論壇貼文的標題」去比對 `scenarios` 資料夾裡每個檔案的檔名（劇本名稱），規則是：

1. 先找標題跟劇本名稱**完全相同**的
2. 找不到的話，再找標題裡**有包含**劇本名稱的（例如貼文標題是「【本週跑團】血染鐘樓」，也抓得到「血染鐘樓」）

所以只要確保：**你每篇劇本論壇貼文的標題，裡面有包含對應劇本檔案的檔名**，這三個指令都能自動判斷。

如果貼文標題跟檔名對不上，機器人會提示你找不到對應資料，這時候可以：
- 修改論壇貼文標題，或
- 修改劇本檔案的**檔名**，讓兩邊一致
- 或直接改用 `/劇本 名稱` 手動指定查詢

### 權限提醒

機器人要能讀到論壇貼文，記得在 Discord 伺服器設定裡，確認機器人角色對該論壇頻道有「檢視頻道」的權限（一般預設都有，除非你有特別鎖權限）。

## 新增劇本資料時的完整欄位

在 `scenarios` 資料夾裡新增一個劇本檔案時（例如 `scenarios/新劇本名稱.json`），檔案內容可以填的欄位如下：

```json
{
  "author": "作者名稱",
  "background": "背景故事，可以用 \n 換行、** ** 加粗",
  "summary": "概要／劇情簡介",
  "public_ho": "公開HO內容，可以用 \n 換行列出多個 HO，例如：\n• **HO1 - 名稱**\nHO1 的簡短描述\n\n• **HO2 - 名稱**\nHO2 的簡短描述",
  "warning": "特殊警告，沒有就填「無」",
  "other": "其他補充事項，沒有就留空字串 \"\"",
  "ho_url": "https://你的HO診斷網址（選填，給 /ho診斷 指令用）",
  "npcs": {
    "NPC名稱1": {
      "description": "NPC簡介文字",
      "image": "https://圖片網址（沒有圖片就留空字串）"
    }
  }
}
```

**注意：檔名本身就是劇本名稱**，不用在檔案內容裡另外寫一次劇本名稱。

### 欄位說明

| 欄位 | 說明 | 必填？ |
|---|---|---|
| `author` | 顯示在劇本卡片裡的「作者」欄位 | 選填 |
| `background` | 顯示在「背景」欄位，適合放世界觀、開場故事 | 選填 |
| `summary` | 顯示在卡片最上方（劇情概要） | 建議填寫 |
| `public_ho` | 顯示在「公開HO」欄位，玩家報名前能看到的角色簡介 | 選填 |
| `warning` | 顯示在「注意事項」欄位，填「無」的話不會顯示這個欄位 | 選填 |
| `other` | 顯示在「其他」欄位，留空字串 `""` 就不會顯示這個欄位 | 選填 |
| `ho_url` | 給 `/ho診斷` 指令用的網址（跟上面的 `public_ho` 是不同功能：`public_ho` 是公開給大家看的角色簡介，`ho_url` 是玩家自己去測驗、分配角色的網站連結）| 選填 |
| `npcs` | 給 `/npc介紹`、`/npc` 指令用的 NPC 資料 | 選填 |

### 排版技巧

`background`、`summary`、`public_ho` 這幾個文字欄位都支援 Discord 的 Markdown 語法：
- `**文字**` → **粗體**
- `\n` → 換行（JSON 裡一定要打 `\n`，不能直接按 Enter）
- `• ` 或 `- ` → 項目符號

### NPC 圖片怎麼取得網址？

把 NPC 圖片傳到你 Discord 伺服器裡的任一頻道 → 對圖片按右鍵 → 「複製圖片連結」→ 貼到 `image` 欄位。沒有圖片的話 `image` 留空字串即可，不會出錯。

改完存檔後，記得重新啟動機器人（Ctrl+C 停止，再打一次 `python bot.py`）才會套用新資料；如果是部署在 Zeabur 上，就是重新部署（Redeploy）。
