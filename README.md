# 跑團劇本查詢機器人

輸入 `/劇本 劇本名稱`，機器人就會回覆該劇本的作者、背景、概要、公開HO 等資訊。

## 新增/修改你自己的劇本

打開 `scenarios` 資料夾，**每個劇本是一個獨立的 .json 檔案**，檔名（去掉 `.json`）就是劇本名稱，例如 `scenarios/血染鐘樓.json`。

- **新增劇本**：在 `scenarios` 資料夾裡新增一個檔案，檔名取成劇本名稱（例如 `scenarios/迷霧莊園.json`），照格式填入內容
- **修改劇本**：直接打開對應的檔案編輯即可

完全**不需要動到 `bot.py` 的程式碼**，也不會因為改了 A 劇本而不小心弄壞 B 劇本的資料（因為是分開的檔案）。完整欄位說明（含 HO 診斷網址、NPC 清單）請見本文件最下方的「新增劇本資料時的完整欄位」。

> 💡 **在 GitHub 網頁上新增劇本檔案的方法**：進到 repository 裡的 `scenarios` 資料夾 → 點 `Add file` → `Create new file` → 檔名直接打成 `劇本名稱.json`（GitHub 會自動放進 scenarios 資料夾底下，只要檔名前面有打 `scenarios/` 或你本來就在這個資料夾頁面裡新增）→ 貼上內容 → `Commit changes`。

> 🛠️ **不想手動對 JSON 格式的話**：可以用附帶的 `[劇本 JSON 產生器](https://taiyang846.github.io/COC/%E5%8A%87%E6%9C%AC%20JSON%20%E7%94%A2%E7%94%9F%E5%99%A8.html)` 這個小工具，打開網頁填表單，就會自動幫你組好格式正確的 JSON 內容，複製貼上到 GitHub 就好，不用擔心漏打逗號、引號這種小細節。

## 目前有的指令

| 指令 | 說明 |
|---|---|
| `/劇本 名稱` | 查詢指定劇本詳細資訊，**可以只打部分關鍵字**，打字時還會即時跳出符合的劇本讓你選（自動完成） |
| `/劇本列表` | 用**下拉選單**列出所有目前收錄的劇本，選了哪個就直接顯示那個劇本的完整資訊 |
| `/劇本資訊` | **在劇本對應的頻道（一般文字頻道或論壇貼文都可以）裡面**打這個指令，機器人會自動判斷「這個頻道對應哪個劇本」，不用輸入名稱 |
| `/ho診斷` | 在劇本對應的頻道裡打這個指令，回覆這個劇本對應的 HO 診斷網址（連結） |
| `/npc介紹` | 在劇本對應的頻道裡打這個指令，列出這個劇本的所有 NPC |
| `/npc 名稱` | 查詢指定 NPC 的介紹，不限定要在哪篇貼文都能查，會列出所有劇本裡符合的 NPC |
| `/抽劇本` | 從所有收錄的劇本裡隨機抽一個出來顯示 |
| `/人數 人數` | 依照遊玩人數，用**下拉選單**列出符合的劇本，例如打 `/人數 4` 會列出支援 4 人遊玩的劇本，選了哪個就直接顯示資訊 |

### 關於下拉選單

`/劇本列表`、`/人數` 這兩個指令，都會跳出 Discord 內建的下拉選單（Select Menu），選單裡的每個選項會順便顯示作者、遊玩人數（如果有填的話），選了之後就會直接顯示那個劇本的完整資訊卡片，不用再打一次 `/劇本 名稱`。

有兩個小限制（來自 Discord 官方的規定，不是機器人的問題）：
- **選單一頁最多只能顯示 25 個選項**：超過 25 個劇本時，機器人會自動加上「◀ 上一頁」「下一頁 ▶」按鈕，可以翻頁看完全部，不會有「劇本太多顯示不完」的問題
- **選單跟按鈕都有 3 分鐘的使用期限**：超過 3 分鐘沒人操作，就會失效，需要重新打一次指令

### `/劇本資訊`、`/ho診斷`、`/npc介紹` 怎麼對應到正確的劇本？

機器人會拿「目前所在頻道的名稱」（不管是一般文字頻道、語音頻道，還是論壇貼文標題都適用）去比對 `scenarios` 資料夾裡每個檔案的檔名（劇本名稱），規則是：

1. 先找頻道名稱跟劇本名稱**完全相同**的
2. 找不到的話，再找頻道名稱裡**有包含**劇本名稱或別名的（例如頻道叫「【本週跑團】血染鐘樓」，也抓得到「血染鐘樓」）

所以只要確保：**每個劇本對應的頻道名稱，裡面有包含對應劇本檔案的檔名（或 aliases 裡的別名）**，這三個指令都能自動判斷。適合你把伺服器裡每個劇本各自開一個文字頻道（或論壇貼文），頻道名稱用劇本名稱來命名。

如果頻道名稱跟檔名對不上，機器人會提示你找不到對應資料，這時候可以：
- 修改頻道名稱，或
- 修改劇本檔案的**檔名**，讓兩邊一致，或
- 幫劇本加上 `aliases` 別名，或
- 直接改用 `/劇本 名稱` 手動指定查詢

### 權限提醒

機器人要能讀到頻道，記得在 Discord 伺服器設定裡，確認機器人角色對這些文字頻道／論壇頻道有「檢視頻道」的權限（一般預設都有，除非你有特別鎖權限）。

### `/劇本` 的關鍵字搜尋怎麼運作？

打 `/劇本` 之後，在名稱欄位打字時，Discord 會**即時顯示符合的劇本名稱**讓你直接點選（這是 Discord 內建的自動完成功能），不用打完整名稱。

就算不用自動完成，直接打關鍵字送出也可以：
- 如果關鍵字只符合**一個**劇本 → 直接顯示那個劇本的資訊
- 如果符合**好幾個**劇本（例如關鍵字太籠統） → 機器人會列出所有符合的劇本名稱，請你打精確一點
- 完全沒有符合的 → 提示找不到，並列出目前所有收錄的劇本

### 劇本名稱是日文，想打中文也查得到？用 `aliases` 欄位

如果你的劇本檔名（正式名稱）是日文，像 `静なるテロリスタ.json`，但你希望玩家打中文關鍵字（例如劇本裡的「美術館」場景）也能找到這個劇本，可以在檔案裡加上 `aliases` 欄位：

```json
{
  "aliases": ["美術館", "沉默的恐怖分子"],
  ...
}
```

這樣不管是 `/劇本` 搜尋、自動完成建議、還是頻道名稱比對（`/劇本資訊`、`/ho診斷`、`/npc介紹`），只要打中文別名都能找到對應的日文劇本。`aliases` 裡可以放任意數量的關鍵字，中文、日文、簡稱都可以混著放。

## 新增劇本資料時的完整欄位

在 `scenarios` 資料夾裡新增一個劇本檔案時（例如 `scenarios/新劇本名稱.json`），檔案內容可以填的欄位如下：

```json
{
  "author": "作者名稱",
  "aliases": ["中文翻譯名稱", "簡稱", "任何你想得到的搜尋關鍵字"],
  "url": "https://劇本網址（選填，設定後劇本標題會變成可點擊的連結）",
  "image": "https://劇本圖片網址（選填，會顯示在劇本資訊卡片下方，沒有就留空字串）",
  "players_min": 3,
  "players_max": 5,
  "background": "背景故事，可以用 \n 換行、** ** 加粗",
  "slogan": "劇本標語",
  "summary": "概要／劇情簡介",
  "public_ho": "公開HO內容，可以用 \n 換行列出多個 HO，例如：\n• **HO1 - 名稱**\nHO1 的簡短描述\n\n• **HO2 - 名稱**\nHO2 的簡短描述",
  "warning": "特殊警告，沒有就填「無」",
  "other": "其他補充事項，沒有就留空字串 \"\"",
  "ho_url": "https://你的HO診斷網址（選填，給 /ho診斷 指令用）",
  "npcs": {
    "NPC名稱1": {
      "description": "NPC簡介文字",
      "image": "https://圖片網址（沒有圖片就留空字串）"
    }
  }
}
```

**注意：檔名本身就是劇本名稱**，不用在檔案內容裡另外寫一次劇本名稱。

### 欄位說明

| 欄位 | 說明 | 必填？ |
|---|---|---|
| `author` | 顯示在劇本卡片裡的「作者」欄位 | 選填 |
| `aliases` | 別名清單，可以放中文翻譯、簡稱、任何搜尋關鍵字。填了之後，用這些關鍵字也能搜尋到這個劇本、頻道名稱用這些名稱也能自動判斷 | 選填 |
| `url` | 劇本的網址（例如論壇貼文、Google Docs），設定後**劇本標題會變成可以點擊的超連結** | 選填 |
| `image` | 劇本本身的圖片（例如封面圖），會顯示在劇本資訊卡片下方 | 選填 |
| `players_min` / `players_max` | 遊玩人數的最少／最多人數（整數）。單人本就兩個都填 `1`。填了才會顯示「遊玩人數」欄位，也是 `/人數` 指令篩選用的依據 | 選填 |
| `background` | 顯示在「背景」欄位 | 選填 |
| `summary` | 劇本介紹 | 建議填寫 |
| `slogan` | 顯示在卡片最上方 | 選填 |
| `public_ho` | 顯示在「公開HO」欄位，玩家報名前能看到的角色簡介 | 選填 |
| `warning` | 顯示在「注意事項」欄位，填「無」的話不會顯示這個欄位 | 選填 |
| `other` | 顯示在「其他」欄位，留空字串 `""` 就不會顯示這個欄位 | 選填 |
| `ho_url` | 給 `/ho診斷` 指令用的網址（跟上面的 `public_ho` 是不同功能：`public_ho` 是公開給大家看的角色簡介，`ho_url` 是玩家自己去測驗、分配角色的網站連結）| 選填 |
| `npcs` | 給 `/npc介紹`、`/npc` 指令用的 NPC 資料 | 選填 |

### 排版技巧

`background`、`summary`、`public_ho` 這幾個文字欄位都支援 Discord 的 Markdown 語法：
- `**文字**` → **粗體**
- `\n` → 換行（JSON 裡一定要打 `\n`，不能直接按 Enter）
- `• ` 或 `- ` → 項目符號

### 圖片怎麼取得網址？

不管是劇本本身的封面圖（`image` 欄位）還是 NPC 的圖片（`npcs` 底下的 `image` 欄位），取得方式都一樣：把圖片傳到你 Discord 伺服器裡的任一頻道 → 對圖片按右鍵 → 「複製圖片連結」→ 貼到對應的 `image` 欄位。沒有圖片的話留空字串即可，不會出錯。

改完存檔後，記得重新啟動機器人（Ctrl+C 停止，再打一次 `python bot.py`）才會套用新資料；如果是部署在 Zeabur 上，就是重新部署（Redeploy）。
